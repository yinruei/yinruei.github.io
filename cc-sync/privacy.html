隱私權政策

最後更新：2026 年 11 月 1 日

適用範圍

「信用卡帳單同步」是開發者本人自用的工具，唯一的使用者是開發者本人。

存取的資料

本工具只申請 Gmail 唯讀權限（https://www.googleapis.com/auth/gmail.readonly），用來搜尋信用卡電子帳單信件並下載其 PDF 附件。不會寄信、刪信或修改任何信件。

資料的使用與保存

下載的帳單只儲存在使用者自己的電腦上，用於個人記帳。授權憑證也只存在本機。

資料分享

本工具不會將任何 Google 使用者資料出售、分享或傳送給第三方，也不用於廣告。

本工具對 Google API 所取得資料的使用，遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

撤銷授權

可隨時到 Google 帳戶的第三方存取權 頁面撤銷本工具的存取權。
